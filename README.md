# Portfolio — Superhero Edition

An interactive 3D portfolio website with a comic-book superhero theme. Features a Three.js city skyline, a web-slinging scroll-driven animation, custom cursor, and GSAP-powered entrance effects.

## Features

- 3D city skyline with procedural window textures
- Scroll-driven "web" that draws across the scene
- Click anywhere to fire a web burst
- Custom cursor with magnetic hover effects
- Comic-style halftone textures and color palette
- Fully responsive

## Tech

HTML, CSS, JavaScript, Three.js, GSAP
